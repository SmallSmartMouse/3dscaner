# 0002 项目文件以自有 JSON 为权威数据

> 状态：已接受 · 日期：2026-10-24

## 背景
RoomPlan 和 Object Capture 都有自己的输出格式（`CapturedRoom` 序列化、USDZ）。直接把它们当作项目数据最省事，但苹果可能改格式；而且平差、点位、卡尺读数这些数据在苹果格式里没有位置。

## 选项
1. **直接存苹果格式**，自有数据另放：实现快；苹果格式变化时老项目可能打不开。
2. **自有 JSON 为权威数据，苹果格式和原始照片作为可重算的输入保留**：多一层转换；格式完全自己掌控。

## 决定
选 2。见技术方案 §5。

## 后果
- 自有格式要有版本号和迁移（AGENTS.md 第 4 节）。
- 原始输入保留，算法改进后老项目可以重算。
- 项目体积更大，提供"清理原始照片"的选项。
