# 0001 STEP 导出只放在 Mac 端

> 状态：已接受 · 日期：2026-10-24

## 背景
物件模式要导出 STEP（特征参考面 + 网格）。成熟的开源实现只有 OpenCASCADE，许可证是 LGPL-2.1（带例外条款）。iOS App 只能静态链接，LGPL 要求用户能替换库重新链接，在 App Store 分发上有合规风险。

## 选项
1. **iOS 内置 OCCT**：用户体验最好；有合规风险，App 体积增加几十 MB。
2. **自写 STEP 写出器**：只写平面、圆柱和三角面片，没有许可证问题；工作量大，兼容性要逐个 CAD 软件验证。
3. **只在 Mac 伴侣 / 服务端用 OCCT**：没有合规问题；没有 Mac 的用户要等云端（P3）。

## 决定
选 3。第一批用户以有 Mac 的创客和工程师为主；P1 阶段没有 Mac 的用户先导出"特征 JSON + 网格"。

## 后果
- Mac 伴侣成为 P1 的必要组件。
- 如果数据显示大量用户没有 Mac，重新评估选项 2。
